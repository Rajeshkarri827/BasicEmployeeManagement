# Employee Management System

A simple Employee Management System built using HTML, CSS, and JavaScript.

## Features

* Add employees
* View employees
* Edit employee details
* Delete employees
* Search employees
* Store employee data using browser localStorage
* Pre-loaded sample employees

## Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Git
* GitHub

## Project Structure

```text
EmployeeManagement/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. You can now add, edit, delete, and search employees.

## Data Storage

This project does not use a backend or database.

Employee information is stored in the browser using JavaScript `localStorage`.
